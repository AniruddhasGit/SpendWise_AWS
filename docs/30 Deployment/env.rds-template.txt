#  1. Replace the THREE bracketed values below.
#  2. Save the whole file as  D:\Project\SpendWise\.env

#  `.env` is gitignored and must NEVER be committed. This template is committed

#  ── The three values ──────────────────────────────────────────────────────
#
#    <ENDPOINT>       your RDS endpoint, e.g. spend-wise-dev-db.abc123.ap-south-1.rds.amazonaws.com
#                     RDS Console → Databases → your instance → "Endpoint"
#    <OWNER_PASSWORD> the password you passed as -v spendwise_owner_password
#    <APP_PASSWORD>   the password you passed as -v spendwise_app_password
#
#  ── TWO THINGS THAT WILL BITE YOU ─────────────────────────────────────────
#
#  1. `?ssl=require` is already on both URLs below. LEAVE IT.
#     RDS forces SSL. asyncpg understands `?ssl=require` and does NOT understand
#     libpq's `sslmode=require` — that spelling is treated as an unknown server
#     setting and the connection fails with an error that never mentions SSL.
#
#  2. If either password contains  @  /  :  #  ?  or  %  it MUST be
#     percent-encoded, or the URL parses the password as part of the hostname
#     and the error names a host you have never heard of. Get the encoded form
#     with:
#
#         py -c "import urllib.parse,getpass; print(urllib.parse.quote(getpass.getpass(), safe=''))"
#
#     Or skip all of this and run  tools\set_credentials.py  instead, which
#     prompts for the values and encodes them for you.

## ─── REQUIRED — the application refuses to start without these ───────────

# Runtime role. Owns no table, is not superuser, holds no BYPASSRLS — asserted
# against the catalog at boot (P-OPS-02). This is what serves every request.
DATABASE_URL=postgresql+asyncpg://spendwise_app:<APP_PASSWORD>@<ENDPOINT>:5432/spendwise?ssl=require

# Owner role. Runs migrations and NOTHING else — it never serves a request.
# Two roles means two connection strings (SW-ADR-081). env.py refuses to start
# if these two are identical.
MIGRATION_DATABASE_URL=postgresql+asyncpg://spendwise_owner:<OWNER_PASSWORD>@<ENDPOINT>:5432/spendwise?ssl=require

# Session signing secret. Must be at least 32 bytes (RFC 7518 §3.2 for HS256) —
# the settings refuse to start below that, because a shorter secret is
# brute-forceable offline from one captured token.
#   REPLACE THIS with your own:  py -c "import secrets; print(secrets.token_urlsafe(48))"
# Rotating it later revokes every live session, by design (SW-ADR-125).
JWT_SECRET=REPLACE_ME_run_the_command_above_at_least_32_bytes_long


## ─── OPTIONAL — sensible defaults, no abort ──────────────────────────────

# (P-ACC-02). Set it to an address NOBODY REGISTERS — the seed creates exactly
