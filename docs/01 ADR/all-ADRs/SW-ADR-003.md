## Context

Whether a date exists, and whether anything real is attached to it, determines whether scope gets cut against the calendar or quality gets cut against it.

## Options considered

- A. No fixed date - quality over speed.
- B. A soft target in weeks.
- C. A hard external date with something attached.

## Decision

**A. No fixed date. Nothing external is attached.**

## Consequences

- Nothing on this project can be 'late'.
- Reopen the instant a date appears. A date arriving later is a SCOPE conversation, not a speed one - adding capacity to a decision-limited project moves nothing.
