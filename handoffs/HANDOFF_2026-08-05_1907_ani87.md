### Traps that are silent — each has cost a round already

- `set_config('app.user_id', …, true)` is **transaction-local**. A second transaction returns
  **zero rows**, not an error — an empty dashboard is indistinguishable from a person who spent
  nothing. One `AsyncSession`, one transaction, GUC as the first statement (`SW-ADR-136`,
  `SW-ADR-144`).
- The day-series `LEFT JOIN` owner predicate goes in **`ON`**, never `WHERE` — in `WHERE` it
  degenerates to an `INNER JOIN`, the zero-spend days vanish, and **only `SIT-E0-S9-05` notices**.
- `SUM()` over `bigint` returns `numeric`. Cast it, or a `Decimal` reaches the response model.
- The three audited admin `GET`s can **never** be cached, replica-served, or run read-only
  (`SW-ADR-135`).
- Per-test reset is `TRUNCATE … RESTART IDENTITY CASCADE` on an **owner** connection, not the
  outer-transaction-rollback pattern — that breaks the transaction-local GUC (`CV-24`).
